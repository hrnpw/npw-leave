## ภาพรวมระบบ

ระบบยื่น/อนุมัติใบลาออนไลน์ เป็นระบบที่พัฒนาขึ้นเพื่ออำนวยความสะดวกให้แก่ครูและบุคลากร
ในการยื่นใบลา ตลอดจนช่วยให้ฝ่ายบุคคลสามารถจัดการและอนุมัติใบลาได้อย่างรวดเร็วและมีประสิทธิภาพ

### จุดเด่นของระบบ

✅ **ใช้งานง่าย** - ออกแบบมาสำหรับมือถือโดยเฉพาะ ใช้งานได้ทุกที่ทุกเวลา  
✅ **รวดเร็ว** - ยื่นใบลาได้ภายใน 3 ขั้นตอน ไม่เกิน 2 นาที  
✅ **โปร่งใส** - ตรวจสอบสถานะใบลาได้แบบเรียลไทม์  
✅ **ปลอดภัย** - ข้อมูลส่วนบุคคลได้รับการปกป้องตามมาตรฐาน  
✅ **แจ้งเตือนอัตโนมัติ** - แจ้งเตือนผ่าน Telegram เมื่อมีใบลาใหม่

### ประเภทการลา

1. **ลาป่วย** - ลาเนื่องจากการเจ็บป่วย
2. **ลากิจส่วนตัว** - ลาเนื่องจากธุระส่วนตัว
3. **ลาคลอดบุตร** - ลาเนื่องจากการคลอดบุตร
4. **ลาทางศาสนา** - ลาไปประกอบพิธีทางศาสนา (เช่น อุปสมบท)
5. **อื่นๆ** - ลาด้วยเหตุผลอื่นที่ไม่ใช่ข้างต้น (ระบุเอง)

### ช่วงเวลาการลา

- **เต็มวัน** - ลาทั้งวัน
- **ครึ่งวันเช้า** - ลาช่วงเช้า (เฉพาะลาวันเดียว)
- **ครึ่งวันบ่าย** - ลาช่วงบ่าย (เฉพาะลาวันเดียว)

## คู่มือสำหรับครู

### 1. เข้าสู่ระบบ

#### วิธีที่ 1: เข้าผ่านเว็บเบราว์เซอร์

1. เปิดเว็บเบราว์เซอร์บนมือถือ (Chrome, Safari, Firefox)
2. พิมพ์ URL: `https://your-app.vercel.app`
3. แตะปุ่ม **"ยื่นใบลา"**
4. กรอกข้อมูล:
   - **เลขบัตรประชาชน** (13 หลัก)
   - **วันเดือนปีเกิด**
5. แตะปุ่ม **"ยืนยันตัวตน"**

#### วิธีที่ 2: ติดตั้งแอปลงหน้าจอโฮม (แนะนำ)

**สำหรับ iPhone/iPad:**
1. เปิดเว็บด้วย Safari
2. แตะปุ่ม "แชร์" (ไอคอนลูกศรขึ้น)
3. เลือก "เพิ่มไปยังหน้าจอโฮม"
4. ตั้งชื่อ "ระบบลาออนไลน์"
5. แตะ "เพิ่ม"

**สำหรับ Android:**
1. เปิดเว็บด้วย Chrome
2. แตะเมนู (จุด 3 จุด)
3. เลือก "เพิ่มไปที่หน้าจอหลัก" หรือ "Install app"
4. ตั้งชื่อ "ระบบลาออนไลน์"
5. แตะ "เพิ่ม"

**ข้อดีของการติดตั้งแอป:**
- เปิดได้เร็วกว่า (ไม่ต้องพิมพ์ URL)
- ทำงานเหมือนแอปธรรมดา
- ใช้งานได้แม้อินเทอร์เน็ตช้า

### 2. ยื่นใบลา (3 ขั้นตอน)

#### ขั้นตอนที่ 1: เลือกประเภทการลา

แตะการ์ดประเภทการลาที่ต้องการ:
- ลาป่วย
- ลากิจส่วนตัว
- ลาคลอดบุตร
- ลาทางศาสนา
- อื่นๆ (ระบุเหตุผล)

หากเลือก **"อื่นๆ"** ระบบจะขอให้ท่านกรอกชื่อประเภทการลา เช่น "ลาไปศาล" "ลาฝึกอบรม"

#### ขั้นตอนที่ 2: เลือกช่วงวันที่ลา

1. แตะวันที่เริ่มลา
2. แตะวันที่สิ้นสุดการลา (หรือวันเดียวกันถ้าลาวันเดียว)
3. เลือกช่วงเวลา:
   - **เต็มวัน** (ค่าเริ่มต้น)
   - **ครึ่งวันเช้า** (เฉพาะลาวันเดียว)
   - **ครึ่งวันบ่าย** (เฉพาะลาวันเดียว)

ระบบจะแสดงจำนวนวันทำการโดยอัตโนมัติ (ไม่นับวันเสาร์-อาทิตย์และวันหยุดราชการ)

**หมายเหตุ:**
- ลาย้อนหลังได้ไม่เกิน 14 วัน
- ลาต่อเนื่องสูงสุด 120 วัน
- หากเลือกวันที่ทับซ้อนกับใบลาที่ยื่นไว้แล้ว ระบบจะแจ้งเตือน

#### ขั้นตอนที่ 3: กรอกรายละเอียด

1. **เหตุผลการลา** (บังคับ - อย่างน้อย 10 ตัวอักษร)
   - อธิบายเหตุผลการลาอย่างชัดเจน
   - ตัวอย่าง: "ป่วยเป็นไข้หวัด มีไข้สูง" หรือ "ธุระส่วนตัวต้องไปธนาคาร"

2. **ที่อยู่ที่สามารถติดต่อได้ระหว่างลา** (บังคับ)
   - ระบบจะนำที่อยู่จากใบลาล่าสุดมาให้อัตโนมัติ
   - สามารถแก้ไขได้

3. **แนบไฟล์** (ไม่บังคับ)
   - ถ่ายรูปหรือเลือกไฟล์จากเครื่อง
   - รองรับ: JPG, PNG, PDF
   - ขนาดไม่เกิน 10 MB ต่อไฟล์
   - แนบได้สูงสุด 5 ไฟล์
   - ระบบจะบีบอัดรูปภาพอัตโนมัติก่อนอัปโหลด

4. แตะปุ่ม **"ยื่นใบลา"**

**หากมีการเตือนเกินเกณฑ์:**
> "การลาครั้งนี้อาจทำให้วันลาสะสมในรอบนี้เกินเกณฑ์ที่กำหนด — ยืนยันการยื่นหรือไม่?"

ท่านสามารถเลือก **"ยืนยัน"** เพื่อยื่นใบลาต่อได้

### 3. ตรวจสอบสถานะใบลา

#### ดูประวัติการลา

1. จากหน้าหลัก แตะแท็บ **"ประวัติ"** ที่ด้านล่าง
2. ระบบจะแสดงรายการใบลาทั้งหมด เรียงจากใหม่สุด

**สถานะใบลา:**
- 🟡 **รออนุมัติ** - รอฝ่ายบุคคลพิจารณา
- 🟢 **อนุมัติแล้ว** - อนุมัติโดยฝ่ายบุคคล
- 🔴 **ไม่อนุมัติ** - ไม่อนุมัติ (ดูเหตุผลได้ในรายละเอียด)
- ⚫ **ยกเลิกแล้ว** - ยกเลิกโดยท่านเอง

#### กรองใบลา

แตะไอคอน **ตัวกรอง** เพื่อกรองตาม:
- **รอบการลา** (รอบ 1: เม.ย.-ก.ย. / รอบ 2: ต.ค.-มี.ค.)
- **ประเภทการลา**
- **สถานะ**

### 4. ยกเลิกใบลา

**เงื่อนไข:** ยกเลิกได้เฉพาะใบลาที่ยังอยู่ในสถานะ **"รออนุมัติ"** เท่านั้น

1. เปิดรายละเอียดใบลา
2. แตะปุ่ม **"ยกเลิกใบลา"**
3. ยืนยันการยกเลิก

**หมายเหตุ:**
- ใบลาที่อนุมัติแล้วไม่สามารถยกเลิกได้ ต้องติดต่อฝ่ายบุคคล
- ใบลาที่ยกเลิกแล้วไม่สามารถกู้คืนได้

### 5. เซสชันหมดอายุ

ระบบจะออกจากระบบอัตโนมัติหลังไม่มีการใช้งาน **1 ชั่วโมง**

**เมื่อเซสชันใกล้หมดอายุ (เหลือ 5 นาที):**
- ระบบจะแสดงข้อความแจ้งเตือน
- มีปุ่ม **"ใช้งานต่อ"** เพื่อต่ออายุเซสชัน

**หากกำลังกรอกใบลา:**
- ข้อมูลที่กรอกจะถูกบันทึกอัตโนมัติใน localStorage
- เมื่อยืนยันตัวตนใหม่ ระบบจะถามว่า "พบใบลาที่กรอกค้างไว้ ต้องการกรอกต่อหรือไม่?"

## คู่มือสำหรับฝ่ายบุคคล (HR)

### 1. เข้าสู่ระบบ

1. เปิดเว็บเบราว์เซอร์ `https://your-app.vercel.app/hr/login`
2. กรอก:
   - **ชื่อผู้ใช้** (username)
   - **รหัสผ่าน** (password)
3. แตะปุ่ม **"เข้าสู่ระบบ"**

**หมายเหตุ:**
- ลองเข้าสู่ระบบผิดเกิน 5 ครั้ง จะถูกล็อก 15 นาที
- เปลี่ยนรหัสผ่านได้ที่เมนู **"ตั้งค่า"** → **"เปลี่ยนรหัสผ่าน"**

### 2. Dashboard

หน้า Dashboard แสดงภาพรวมระบบ:

**การ์ดสรุป 5 ใบ:**
1. **มาปฏิบัติงาน** - จำนวนครูที่มาทำงานวันนี้
2. **ลาวันนี้** - จำนวนครูที่ลาวันนี้ (แตะดูรายชื่อได้)
3. **ลาพรุ่งนี้** - จำนวนครูที่ลาพรุ่งนี้
4. **รออนุมัติ** - จำนวนใบลารออนุมัติ (แตะไปหน้าอนุมัติ)
5. **เกินเกณฑ์** - จำนวนครูที่ลาเกินโควตา

**ส่วนอื่นๆ:**
- ปฏิทิน Heatmap - แสดงจำนวนคนลาต่อวัน (แตะดูรายชื่อได้)
- กราฟแท่ง - สัดส่วนประเภทการลา
- รายการอนุมัติแล้วยังไม่พิมพ์ - พร้อมปุ่มพิมพ์รายแถว
- แจ้งเตือนที่ส่งไม่สำเร็จ - พร้อมปุ่มส่งซ้ำ

**เมนูด้านล่าง (มือถือ):**
- Dashboard
- รออนุมัติ (มี badge แสดงจำนวน)
- ใบลา
- เพิ่มเติม

### 3. อนุมัติ/ไม่อนุมัติใบลา

#### วิธีที่ 1: อนุมัติทีละใบ (มือถือ)

1. ไปที่แท็บ **"รออนุมัติ"**
2. **ปัดการ์ดไปทางขวา** = อนุมัติ (มือถือสั่นเบาๆ)
3. **ปัดการ์ดไปทางซ้าย** = ไม่อนุมัติ (ต้องกรอกเหตุผล)

#### วิธีที่ 2: อนุมัติหลายใบพร้อมกัน

1. แตะไอคอน **☑** มุมขวาบน
2. เลือกใบลาที่ต้องการอนุมัติ
3. แตะปุ่ม **"อนุมัติที่เลือก"**

#### วิธีที่ 3: อนุมัติจากหน้ารายละเอียด

1. แตะการ์ดใบลา
2. ตรวจสอบข้อมูล:
   - ชื่อครู, ประเภทการลา
   - ช่วงวัน, จำนวนวันทำการ/ปฏิทิน
   - เหตุผล, ที่อยู่ติดต่อ
   - ไฟล์แนบ (ถ้ามี)
   - **วันลาสะสมในรอบ** (ดูว่าเกินเกณฑ์หรือไม่)
3. แตะปุ่ม **"อนุมัติ"** หรือ **"ไม่อนุมัติ"**

**ป้ายพิเศษ:**
- 🕐 **ย้อนหลัง** - ยื่นย้อนหลังเกิน 3 วัน
- 🖊️ **ยื่นโดย {ชื่อ HR}** - ฝ่ายบุคคลยื่นแทนครู

**การแจ้งเตือน:**
หากใบลาเกินเกณฑ์ จะมีแถบสีแดงแสดง เช่น:
> "⚠️ 25.5 / 23 วัน เกิน 2.5 วัน"

### 4. ยื่นใบลาแทนครู

**กรณีใช้งาน:** ครูไม่สะดวกใช้มือถือ หรือยื่นเอกสารกระดาษที่ห้องธุรการ

#### ขั้นตอน

**Step 0: เลือกครู**
1. ไปที่ **"ยื่นใบลาแทนครู"**
2. ค้นหาครูจากชื่อ/รหัส
3. เลือกเหตุผลที่ยื่นแทน:
   - ครูไม่สะดวกใช้งานระบบออนไลน์
   - ครูยื่นเอกสารกระดาษ
   - ครูลาป่วยกะทันหันแจ้งทางโทรศัพท์
   - อื่นๆ (ระบุ)

**Step 1-3:** ดำเนินการเหมือนครูยื่นเอง (3 ขั้นตอน)

**ยืนยัน:**
- ติ๊ก "ยืนยันว่าได้รับความยินยอมจากครูแล้ว"
- แตะปุ่ม **"ส่ง"**

**หมายเหตุ:**
- ใบลาที่ยื่นแทนจะมีสถานะ "รออนุมัติ" เหมือนกัน
- **HR/Super Admin ยื่นให้ตัวเองไม่ได้**
- ครูจะเห็นป้าย "ยื่นโดยฝ่ายบุคคล" ในประวัติของเขา
- Telegram แจ้งเตือนพร้อมระบุว่ายื่นแทนโดยใคร

### 5. จัดการใบลา

#### ค้นหา/กรอง

1. ไปที่แท็บ **"ใบลา"**
2. ใช้ช่องค้นหา: ชื่อ/รหัส/เลขที่ใบลา
3. ตัวกรอง:
   - รอบการลา
   - ประเภทการลา
   - สถานะ
   - ช่วงวันที่
   - **ครูยื่นเอง / HR ยื่นแทน**

#### แก้ไขใบลา

**ใบลาที่อนุมัติแล้ว** - แก้ไขได้เฉพาะ:
- ประเภทการลา
- ช่วงวันที่
- เหตุผล
- ที่อยู่ติดต่อ

**ห้ามแก้:**
- สถานะ (ย้อนสถานะทำได้เฉพาะ super admin)
- ผู้ลงนาม (ใช้ชื่อตอนอนุมัติครั้งแรก)

#### ยกเลิกใบลา

- ใบลา "รออนุมัติ" - ยกเลิกได้เลย
- ใบลา "อนุมัติแล้ว" - ยกเลิกได้ (บันทึก audit log)

### 6. พิมพ์ PDF ใบลา

#### วิธีพิมพ์

1. เปิดรายละเอียดใบลา (สถานะ "อนุมัติแล้ว")
2. แตะปุ่ม **"พิมพ์ PDF"**
3. รอสักครู่ (3-6 วินาที สำหรับครั้งแรก)
4. PDF จะเปิดในแท็บใหม่
5. แตะปุ่ม "Print" เพื่อพิมพ์หรือบันทึก

**PDF ประกอบด้วย:**
- ข้อมูลครู, ประเภทการลา, ช่วงวัน
- จำนวนวันทำการ (ไม่ใช่วันปฏิทิน)
- เหตุผล, ที่อยู่ติดต่อ
- ตารางสถิติ: ลามาแล้ว / ลาครั้งนี้ / รวมเป็น
- 3 ช่องลงนาม + ลายเซ็น (ถ้ามี)
- QR Code ตรวจสอบความถูกต้อง
- เลขที่ใบลา (มุมขวาบน)

**หมายเหตุ:**
- พิมพ์ได้เฉพาะใบที่อนุมัติแล้ว
- พิมพ์ได้ทีละใบเท่านั้น
- ฟอนต์ไทยแสดงผลถูกต้อง 100%

### 7. จัดการครู

#### ดูรายชื่อครู

1. ไปที่เมนู **"ครู"** หรือ **"เพิ่มเติม"** → **"จัดการครู"**
2. แสดงรายการครูทั้งหมด (การ์ดบนมือถือ / ตารางบนเดสก์ท็อป)
3. ข้อมูลแต่ละคน: รหัส, ชื่อ-นามสกุล, ตำแหน่ง, กลุ่มสาระ, สถานะ

#### ค้นหา/กรอง

- **ค้นหา:** พิมพ์ชื่อ/รหัส/เลขบัตร (realtime, debounce 300ms)
- **กรอง:**
  - สถานะ: ใช้งาน / ปิดใช้งาน
  - กลุ่มสาระ

#### เพิ่มครูรายคน

1. แตะปุ่ม **"เพิ่มครู"**
2. กรอกข้อมูล:
   - รหัสประจำตัวครู (ไม่บังคับ - ระบบ gen T-0001 อัตโนมัติ)
   - คำนำหน้า (นาย/นาง/นางสาว/ฯลฯ)
   - ชื่อ-นามสกุล
   - เลขบัตรประชาชน 13 หลัก (ตรวจ checksum)
   - วันเดือนปีเกิด (พ.ศ. หรือ ค.ศ.)
   - ตำแหน่ง
   - กลุ่มสาระ/ฝ่าย (ไม่บังคับ)
   - เบอร์โทร (ไม่บังคับ)
3. แตะ **"บันทึก"**

**การตรวจสอบ:**
- เลขบัตร 13 หลัก + checksum ถูกต้อง
- เลขบัตรไม่ซ้ำในระบบ
- รหัสครูไม่ซ้ำ (ถ้ากรอก)

#### แก้ไขข้อมูลครู

1. แตะการ์ดครู → **"แก้ไข"**
2. แก้ไขฟิลด์ที่ต้องการ
3. แตะ **"บันทึก"**

**หมายเหตุ:**
- **เลขบัตรประชาชน** แก้ได้เฉพาะ **Super Admin**
- **รหัสครู** แก้ได้โดย HR ทั่วไป

#### ปิด/เปิดใช้งานครู

1. แตะการ์ดครู → **"ปิดใช้งาน"**
2. ยืนยัน

**ผลกระทบ:**
- ครูที่ปิดใช้งาน: ยืนยันตัวตนไม่ได้, HR ยื่นแทนไม่ได้
- ประวัติการลายังอยู่ครบ

#### ลบครูถาวร (Super Admin เท่านั้น)

- ลบได้เฉพาะครูที่ **ไม่มีใบลาในระบบ**
- หากมีใบลาแล้ว ต้องใช้ "ปิดใช้งาน" แทน

#### Import ครูจาก Excel

**ขั้นตอน:**

1. แตะปุ่ม **"นำเข้าจาก Excel"**
2. ดาวน์โหลด Template
3. กรอกข้อมูลใน Excel:

| คอลัมน์ | บังคับ | หมายเหตุ |
|---------|:------:|----------|
| รหัสประจำตัวครู | ไม่ | เว้นว่าง = gen T-000x |
| คำนำหน้า | ✓ | นาย/นาง/นางสาว |
| ชื่อ | ✓ | |
| นามสกุล | ✓ | |
| เลขบัตรประชาชน | ✓ | 13 หลัก ไม่ต้องใส่ขีด |
| วันเกิด | ✓ | พ.ศ./ค.ศ. (ปี > 2400 = พ.ศ.) |
| ตำแหน่ง | ✓ | |
| กลุ่มสาระ/ฝ่าย | ไม่ | เว้นว่าง = "ไม่ระบุ" |
| เบอร์โทร | ไม่ | |

4. เลือกไฟล์ที่กรอกแล้ว
5. ระบบตรวจสอบและแสดงผล:
   - ✅ ถูกต้อง (N รายการ)
   - ⚠️ เตือน - เลขบัตรซ้ำในระบบ (เลือก: ข้าม/อัปเดต)
   - ❌ ผิดพลาด - เลขบัตรซ้ำในไฟล์/checksum ผิด (ต้องแก้)
6. พรีวิวข้อมูล
7. เลือก:
   - **ข้ามแถวที่ผิดพลาด** (นำเข้าเฉพาะที่ถูกต้อง)
   - **อัปเดตข้อมูลเดิม** (กรณีซ้ำในระบบ)
8. แตะ **"นำเข้า"**

**ข้อจำกัด:**
- สูงสุด 500 แถว/ครั้ง
- หากเลขบัตรซ้ำกันเองในไฟล์ → ❌ ทั้ง 2 แถวต้องแก้

#### Export รายชื่อครู

1. แตะปุ่ม **"ส่งออก Excel"**
2. ไฟล์ดาวน์โหลดอัตโนมัติ: `teachers-YYYYMMDD.xlsx`

**ข้อมูลที่ส่งออก:**
- รหัส, ชื่อ-นามสกุล, ตำแหน่ง, กลุ่มสาระ
- เลขบัตร (ปกปิด: 1-2345-xxxxx-xx-3)
- วันเกิด, เบอร์โทร, สถานะ

### 8. จัดการวันหยุดราชการ

1. ไปที่เมนู **"วันหยุดราชการ"**
2. เลือกปี (พ.ศ.)
3. แสดงรายการวันหยุดของปีนั้น

#### เพิ่มวันหยุด

**เพิ่มทีละวัน:**
1. แตะปุ่ม **"เพิ่มวันหยุด"**
2. เลือกวันที่
3. กรอกชื่อวันหยุด (เช่น "วันสงกรานต์")
4. บันทึก

**เพิ่มเป็นช่วง:**
1. แตะปุ่ม **"เพิ่มช่วงวันหยุด"**
2. เลือกวันเริ่มต้น-สิ้นสุด
3. กรอกชื่อวันหยุด
4. บันทึก

#### คัดลอกจากปีก่อน

1. แตะปุ่ม **"คัดลอกจากปีก่อน"**
2. ระบบคัดลอกวันหยุดจากปีที่แล้วมาปีปัจจุบัน
3. ตรวจสอบและแก้ไขวันที่ (เพราะบางวันหยุดเลื่อนปีต่อปี)

#### แก้ไข/ลบวันหยุด

- แตะรายการวันหยุด → **"แก้ไข"** หรือ **"ลบ"**

**หมายเหตุ:**
- แก้ไขย้อนหลังได้ แต่ **ไม่คำนวณใบลาเก่าใหม่**
- ระบบจะแสดง "ใบลาที่อาจได้รับผลกระทบ" ให้ตรวจสอบ
- ระบบเตือนถ้าถึง 1 ธ.ค. ยังไม่มีข้อมูลปีถัดไป

### 9. จัดการผู้ลงนาม

1. ไปที่เมนู **"ผู้ลงนาม"**
2. แสดงรายการผู้ลงนามทั้งหมด

#### เพิ่มผู้ลงนาม

1. แตะปุ่ม **"เพิ่มผู้ลงนาม"**
2. กรอกข้อมูล:
   - บทบาท: ผู้อำนวยการ / หัวหน้าฝ่ายบุคคล
   - คำนำหน้า, ชื่อ, นามสกุล
   - ตำแหน่ง (เช่น "ผู้อำนวยการโรงเรียนบ้านเนินพลับหวาน")
   - ไฟล์ลายเซ็น (PNG พื้นหลังโปร่ง, ไม่บังคับ)
3. บันทึก

#### เลือกผู้ลงนามปัจจุบัน

1. ในแต่ละบทบาท เลือกผู้ลงนามปัจจุบัน:
   - **ผู้อำนวยการ** (ผู้อนุญาต)
   - **หัวหน้าฝ่ายบุคคล** (ผู้บังคับบัญชา)
2. แตะ **"บันทึก"**

**หมายเหตุ:**
- เมื่ออนุมัติใบลา ระบบจะ **snapshot ชื่อ+ตำแหน่ง** ลงใบลาทันที
- PDF ใช้ค่า snapshot (ไม่ใช่ตัวปัจจุบัน)
- เปลี่ยนผู้ลงนาม → ใบลาเก่าแสดงชื่อคนเดิม, ใบใหม่แสดงชื่อคนใหม่

#### แก้ไข/ปิดใช้งาน

- แตะรายการผู้ลงนาม → **"แก้ไข"** หรือ **"ปิดใช้งาน"**
- ห้ามลบ (เพราะใบลาเก่าอ้างอิง)

### 10. รายงาน (5 ชุด)

ไปที่เมนู **"รายงาน"** จะเห็นการ์ด 5 ใบ:

#### 1. สรุปการลารายรอบ

**แสดง:**
- รหัส, ชื่อครู
- ป่วย (ทำการ/ปฏิทิน)
- กิจ (ทำการ/ปฏิทิน)
- รวม ป่วย+กิจ
- สถานะเกิน (เกิน 23 วัน → ไฮไลต์แดง)
- คลอดบุตร
- ทางศาสนา
- อื่นๆ

**ตัวกรอง:**
- รอบการลา
- กลุ่มสาระ

**Export:** แตะปุ่ม **"Export Excel"**

#### 2. รายการใบลาทั้งหมด

**แสดง:**
- เลขที่, ครู, ประเภท, ช่วงวัน, สถานะ
- จำนวนวัน (ทำการ/ปฏิทิน)
- วันที่ยื่น, วันที่อนุมัติ

**ตัวกรอง:**
- รอบการลา
- ประเภท
- สถานะ
- ช่วงวันที่
- **ครูยื่นเอง / HR ยื่นแทน**

**Export:** Excel พร้อมทุกฟิลด์

#### 3. สถิติรายกลุ่มสาระ/ฝ่าย

**แสดง:**
- กลุ่มสาระ
- จำนวนครู
- วันลาเฉลี่ยต่อคน
- วันลารวม

**ตัวกรอง:**
- รอบการลา

**Export:** Excel

#### 4. รายงานใบลาที่ยื่นแทน

**แสดง:**
- เลขที่ใบลา
- ครู
- HR ผู้ยื่น
- วันที่ยื่น
- เหตุผลที่ยื่นแทน
- หมายเหตุ

**ตัวกรอง:**
- ช่วงวันที่
- HR ผู้ยื่น

**Export:** Excel

#### 5. Audit Log

**แสดง:**
- วันที่/เวลา
- ผู้ใช้ (HR/Super Admin)
- การกระทำ (เช่น "อนุมัติใบลา", "แก้ไขครู")
- รายละเอียด (before/after)
- IP Address

**ตัวกรอง:**
- ช่วงวันที่
- ผู้ใช้
- การกระทำ

**สิทธิ์:**
- HR เห็นได้ **90 วันล่าสุด**
- Super Admin เห็น**ทั้งหมด** + Export ได้

### 11. จัดการพื้นที่ไฟล์แนบ (Blob Storage)

1. ไปที่เมนู **"จัดการพื้นที่"**
2. แสดง:
   - **Progress Bar**: X MB / 1024 MB
   - สีเตือน: 🟢 < 70% / 🟠 70-90% / 🔴 > 90%
   - **50 ใบลาที่มีไฟล์ใหญ่สุด**

#### ลบไฟล์แนบ

1. แตะปุ่ม **"ลบไฟล์"** ในแถวใบลา
2. ยืนยันการลบ
3. ไฟล์ถูกลบจาก Blob ถาวร

**คำเตือน:**
> "⚠️ เกินโควตา 1 GB = Vercel ตัดการเข้าถึง Blob 30 วัน"

**การลบไฟล์อัตโนมัติ:**
- ครูยกเลิกใบลา
- Super admin ลบใบลา
- ล้างข้อมูลทดสอบ

### 12. ตั้งค่า

1. ไปที่เมนู **"ตั้งค่า"**

#### ส่วนที่ 1: ตั้งค่าทั่วไป (HR + Super Admin)

- **ชื่อโรงเรียน**
- **ย้อนหลังได้ (ครู):** 0-90 วัน (ค่าเริ่มต้น 14)
- **ย้อนหลังได้ (HR):** 0-90 วัน (ค่าเริ่มต้น 30)

#### ส่วนที่ 2: โควตาวันลา (Super Admin เท่านั้น)

- **ป่วย+กิจส่วนตัว:** 1-365 วัน (ค่าเริ่มต้น 23)
- **คลอดบุตร:** 1-365 วัน (ค่าเริ่มต้น 90)
- **ทางศาสนา:** 1-365 วัน (ค่าเริ่มต้น 120)

**หมายเหตุ:**
- โควตาเทียบจาก **วันปฏิทิน** (รวมเสาร์-อาทิตย์+วันหยุด)
- ระบบเตือนเท่านั้น ไม่บล็อก

#### ส่วนที่ 3: ผู้ลงนาม (HR + Super Admin)

- เลือกผู้อำนวยการปัจจุบัน
- เลือกหัวหน้าฝ่ายบุคคลปัจจุบัน
- ลิงก์ไปหน้า "จัดการผู้ลงนาม"

#### ส่วนที่ 4: Telegram (Super Admin เท่านั้น)

- **Bot Token** (ปกปิด, มีปุ่ม แสดง/ซ่อน)
- **Chat ID**
- ปุ่ม **"ทดสอบส่ง"**

**การแจ้งเตือน:**
- แจ้งใบลาใหม่ทันที (≤10 วินาที)
- สรุปประจำวัน 08:00 น.

#### เปลี่ยนรหัสผ่าน (HR + Super Admin)

1. เมนู **"ตั้งค่า"** → **"เปลี่ยนรหัสผ่าน"**
2. กรอก:
   - รหัสผ่านเดิม
   - รหัสผ่านใหม่ (อย่างน้อย 8 ตัว)
   - ยืนยันรหัสผ่านใหม่
3. บันทึก

## คู่มือสำหรับผู้ดูแลระบบ (Super Admin)

Super Admin มีสิทธิ์เต็มในระบบ รวมถึง:
- ทุกสิทธิ์ของ HR
- จัดการบัญชี HR
- ตั้งค่าโควตา
- ตั้งค่า Telegram
- เข้าถึง Audit Log เต็มรูปแบบ
- โซนอันตราย (ลบ/รีเซ็ต/ย้อนสถานะ)

### 1. เข้าสู่โซน Super Admin

1. ล็อกอินด้วยบัญชี Super Admin
2. ไปที่เมนู **"Admin"** หรือ **"เพิ่มเติม"** → **"ผู้ดูแลระบบ"**
3. จะเห็น 4 แท็บ:
   - **จัดการบัญชีเจ้าหน้าที่**
   - **สถานะระบบ**
   - **Audit Log**
   - **โซนอันตราย**

### 2. จัดการบัญชีเจ้าหน้าที่

#### ดูรายการบัญชี HR

แสดง:
- Username
- ชื่อ-นามสกุล
- บทบาท (HR / Super Admin)
- สถานะ (เปิด/ปิดใช้งาน)
- เข้าสู่ระบบล่าสุด

#### เพิ่มบัญชี HR

1. แตะปุ่ม **"เพิ่มบัญชี"**
2. กรอกข้อมูล:
   - Username (3-50 ตัว, a-z A-Z 0-9 _)
   - ชื่อ-นามสกุล
   - รหัสผ่าน (อย่างน้อย 8 ตัว)
   - บทบาท: HR / Super Admin
3. บันทึก

**การตรวจสอบ:**
- Username ต้องไม่ซ้ำ
- รหัสผ่าน hash ด้วย scrypt

#### แก้ไขบัญชี HR

1. แตะการ์ดบัญชี → **"แก้ไข"**
2. แก้ไข: ชื่อ-นามสกุล, บทบาท, สถานะ
3. บันทึก

**ห้ามแก้:**
- Username (ไม่สามารถแก้ได้)
- ไม่สามารถแก้ไขบัญชีตัวเองได้

#### รีเซ็ตรหัสผ่าน

1. แตะการ์ดบัญชี → **"รีเซ็ตรหัสผ่าน"**
2. กรอกรหัสผ่านใหม่
3. ยืนยัน

**หมายเหตุ:**
- ไม่สามารถรีเซ็ตรหัสผ่านตัวเองได้
- แจ้งรหัสผ่านใหม่ให้ผู้ใช้ทราบ

#### ลบบัญชี HR

1. แตะการ์ดบัญชี → **"ลบ"**
2. ยืนยัน (2 ชั้น)

**ข้อจำกัด:**
- ต้องมี Super Admin อย่างน้อย 1 บัญชีเสมอ
- ไม่สามารถลบบัญชีตัวเองได้
- ลบแล้วไม่สามารถกู้คืนได้

### 3. สถานะระบบ

แสดงการ์ด 4 ใบ:

#### 1. ฐานข้อมูล
- 🟢 เชื่อมต่อสำเร็จ / 🔴 เชื่อมต่อไม่สำเร็จ
- Ping time (ms)

#### 2. พื้นที่ Blob
- X MB / 1024 MB
- Progress Bar สีตามระดับ
- คำเตือนถ้าใกล้เต็ม

#### 3. Telegram
- ✅ ตั้งค่าแล้ว / ❌ ยังไม่ตั้งค่า
- ปุ่ม **"ทดสอบส่ง"**

#### 4. Cron Job
- เวลารันล่าสุด
- ผลลัพธ์: สำเร็จ / ล้มเหลว

#### 5. สถิติระบบ
- จำนวนครูทั้งหมด (เปิด/ปิด)
- จำนวนใบลาทั้งหมด
- จำนวนไฟล์แนบ

**ปุ่ม Refresh:** แตะเพื่ออัปเดตข้อมูล

### 4. Audit Log

- เห็นทั้งหมด (ไม่จำกัด 90 วัน)
- Export ได้
- ค้นหา/กรองตามผู้ใช้/การกระทำ/ช่วงเวลา

### 5. โซนอันตราย ⚠️

**คำเตือน:**
> "การกระทำในส่วนนี้อาจส่งผลกระทบต่อข้อมูลในระบบ กรุณาดำเนินการด้วยความระมัดระวัง"

มี 4 การกระทำ แต่ละอย่างต้องผ่าน **2 ชั้น**:

#### 1. ล้างข้อมูลทดสอบ (สีแดง)

**ลบ:**
- ใบลาทั้งหมด
- ไฟล์แนบ (จาก Blob)
- Fiscal counters
- Notification queue

**ไม่ลบ:**
- ครู
- บัญชี HR
- วันหยุด
- ผู้ลงนาม
- ตั้งค่า

**ขั้นตอน:**
1. แตะปุ่ม **"ล้างข้อมูลทดสอบ"**
2. Bottom sheet แสดงผลกระทบ
3. พิมพ์ **"ยืนยันล้างข้อมูล"** (ตรงตัว)
4. ยืนยัน

**ใช้เมื่อ:**
- หลังทดสอบระบบเสร็จ
- ต้องการเริ่มต้นใหม่

#### 2. รีเซ็ตเลขรันนิ่งใบลา (สีแดง)

**กระทำ:**
- รีเซ็ต running number ของปีงบประมาณที่ระบุเป็น 0000

**ขั้นตอน:**
1. แตะปุ่ม **"รีเซ็ตเลขรันนิ่ง"**
2. พิมพ์ **"ยืนยันรีเซ็ต"** (ตรงตัว)
3. กรอกปีงบประมาณ พ.ศ. (2560-2600)
4. ยืนยัน

**ข้อจำกัด:**
- หากมีใบลาในปีนั้นแล้ว จะรีเซ็ตไม่ได้

**ใช้เมื่อ:**
- ข้ามปีงบประมาณใหม่แล้วต้องการรีเซ็ตเลข

#### 3. ย้อนสถานะใบลา (สีแดง)

**กระทำ:**
- เปลี่ยนสถานะจาก "อนุมัติแล้ว" → "รออนุมัติ"
- เก็บ signatory snapshot (ไม่เปลี่ยน)

**ขั้นตอน:**
1. แตะปุ่ม **"ย้อนสถานะใบลา"**
2. Bottom sheet แสดงคำเตือน
3. กรอกเลขที่ใบลา (LV-YYYY-NNNN) ที่ต้องการย้อน
4. ยืนยัน

**ใช้เมื่อ:**
- อนุมัติผิด ต้องการแก้ไขก่อนพิมพ์

#### 4. Export ฐานข้อมูลทั้งหมด (สีเหลือง)

**Export:**
- Excel 7 sheets:
  1. Teachers
  2. HR Users (ไม่มีรหัสผ่าน)
  3. Leaves
  4. Attachments
  5. Holidays
  6. Signatories
  7. Settings (Telegram token ปกปิด)

**ขั้นตอน:**
1. แตะปุ่ม **"Export ฐานข้อมูล"**
2. ยืนยัน
3. ดาวน์โหลด: `database-backup-YYYYMMDD.xlsx`

**ใช้เมื่อ:**
- สำรองข้อมูลก่อน deploy
- ต้องการวิเคราะห์ข้อมูลใน Excel

## คำถามที่พบบ่อย (FAQ)

### ครู

**Q: ลืมเลขบัตรประชาชน/วันเกิด?**  
A: ติดต่อฝ่ายบุคคลเพื่อขอข้อมูล ระบบไม่มีฟีเจอร์ "ลืมรหัสผ่าน"

**Q: ยื่นใบลาผิด ต้องการแก้ไข?**  
A: หากยังอยู่สถานะ "รออนุมัติ" → ยกเลิกแล้วยื่นใหม่  
หากอนุมัติแล้ว → ติดต่อฝ่ายบุคคล

**Q: ยื่นใบลาแล้วไม่เห็นในประวัติ?**  
A: ตรวจสอบว่ายื่นสำเร็จหรือไม่ (ต้องเห็น toast "ยื่นใบลาสำเร็จ")  
ลองดึงรายการใหม่ (pull-to-refresh)

**Q: เซสชันหมดอายุบ่อยเกินไป?**  
A: เซสชันมีอายุ 1 ชั่วโมง หากกำลังกรอกฟอร์มข้อมูลจะถูกบันทึก  
แตะปุ่ม "ใช้งานต่อ" เมื่อเตือน (เหลือ 5 นาที)

**Q: อัปโหลดรูปล้มเหลว?**  
A: ตรวจสอบ:
- ขนาดไฟล์ ≤ 10 MB
- รูปแบบ JPG/PNG/PDF เท่านั้น
- มีอินเทอร์เน็ต
- Blob Storage เหลือพื้นที่

**Q: ลาครึ่งวันได้กี่ประเภท?**  
A: ได้ทุกประเภท (ป่วย/กิจ/คลอด/ศาสนา/อื่นๆ) << แก้ไข

**Q: ระบบแสดงว่าเกินเกณฑ์ แต่ยื่นได้ปกติ?**  
A: ถูกต้อง ระบบเตือนเท่านั้น ไม่บล็อก  
การพิจารณาขึ้นอยู่กับฝ่ายบุคคลและผู้บริหาร

### HR/Super Admin

**Q: ลืมรหัสผ่าน HR?**  
A: ติดต่อ Super Admin เพื่อรีเซ็ตรหัสผ่าน

**Q: Telegram ไม่ส่ง?**  
A: ตรวจสอบ:
1. Bot Token + Chat ID ถูกต้อง
2. ทดสอบส่งใน Settings
3. ดู "แจ้งเตือนที่ส่งไม่สำเร็จ" ใน Dashboard → กดส่งซ้ำ

**Q: PDF แสดงภาษาไทยเป็นสี่เหลี่ยม?**  
A: ไม่ควรเกิด (embed font แล้ว)  
หากเกิด → แจ้งผู้ดูแลระบบตรวจสอบ Puppeteer config

**Q: Import ครูบอกว่าเลขบัตรซ้ำ แต่ไม่เห็นในระบบ?**  
A: อาจซ้ำกับครูที่ **ปิดใช้งาน**  
ระบบจะเสนอ "เปิดใช้งานคืน + อัปเดต"

**Q: อนุมัติผิด ต้องการย้อนสถานะ?**  
A: ติดต่อ Super Admin ใช้ฟีเจอร์ "ย้อนสถานะใบลา" ในโซนอันตราย

**Q: เปลี่ยนผู้ลงนาม แล้วใบลาเก่าเปลี่ยนด้วย?**  
A: ไม่เปลี่ยน PDF ใช้ชื่อตอน snapshot (ตอนอนุมัติ)

**Q: ครูถูกล็อกเพราะลองเข้าผิด แก้ไงได้?**  
A: รอ 15 นาทีหรือล็อกอินใหม่หลัง 15 นาที  
(ระบบไม่มีฟีเจอร์ปลดล็อกด้วยตนเอง)

**Q: ลบครูไม่ได้?**  
A: ครูที่มีใบลาแล้วลบไม่ได้ ต้องใช้ "ปิดใช้งาน" แทน

## การแก้ปัญหาเบื้องต้น

### ปัญหาการเข้าสู่ระบบ

| อาการ | สาเหตุ | วิธีแก้ |
|-------|--------|---------|
| "ข้อมูลไม่ถูกต้อง" | เลขบัตร/วันเกิด/username/password ผิด | ตรวจสอบข้อมูลอีกครั้ง |
| "บัญชีถูกระงับ" | ครู/HR ถูกปิดใช้งาน | ติดต่อฝ่ายบุคคล/Super Admin |
| "ลองเข้าสู่ระบบผิดหลายครั้ง" | ล็อก 15 นาที | รอครบ 15 นาที |
| เข้าแล้วถูก logout ทันที | SESSION_SECRET ไม่ถูกต้อง | ติดต่อผู้ดูแลระบบ |

### ปัญหาการยื่นใบลา

| อาการ | สาเหตุ | วิธีแก้ |
|-------|--------|---------|
| "วันที่ทับซ้อนกับใบลาที่ยื่นไว้" | มีใบลาช่วงนั้นแล้ว (รออนุมัติ/อนุมัติ) | เลือกช่วงวันอื่น หรือยกเลิกใบเดิม |
| "ย้อนหลังเกินกำหนด" | ยื่นย้อนหลัง > 14 วัน (ครู) / 30 วัน (HR) | เลือกวันใหม่กว่า |
| "ช่วงลาเกิน 120 วัน" | ลาต่อเนื่อง > 120 วัน | แบ่งเป็น 2 ใบลา |
| อัปโหลดไฟล์ล้มเหลว | ขนาดเกิน 10MB / ไฟล์ไม่รองรับ / Blob เต็ม | บีบอัดรูป / ใช้ PDF / ติดต่อ HR |

### ปัญหา PDF

| อาการ | สาเหตุ | วิธีแก้ |
|-------|--------|---------|
| กดพิมพ์แล้วไม่เห็นอะไร | กำลัง loading (cold start 3-6 วิ) | รอสักครู่ |
| ภาษาไทยเป็นสี่เหลี่ยม | Puppeteer config ผิด (production) | แจ้งผู้ดูแลระบบ |
| PDF ไม่มีลายเซ็น | ไม่ได้อัปโหลดลายเซ็นใน Settings | เพิ่มลายเซ็นผู้ลงนาม |
| ชื่อผู้ลงนามผิด | แก้ใน Settings แต่ไม่ snapshot ใหม่ | ใบลาเก่าใช้ชื่อเดิม (ถูกต้อง) |

### ปัญหา Telegram

| อาการ | สาเหตุ | วิธีแก้ |
|-------|--------|---------|
| ไม่ได้รับแจ้งเตือน | Token/Chat ID ผิด / Bot ไม่ได้อยู่ในกลุ่ม | ทดสอบส่งใน Settings |
| แจ้งเตือนช้า | Retry 3 ครั้งก่อนบันทึก queue | ตรวจสอบอินเทอร์เน็ต |
| ส่งซ้ำไม่สำเร็จ | Token หมดอายุ / Bot ถูกเตะออกจากกลุ่ม | ตรวจสอบ Bot |

### ปัญหาทั่วไป

| อาการ | สาเหตุ | วิธีแก้ |
|-------|--------|---------|
| หน้าเว็บโหลดช้า | อินเทอร์เน็ตช้า / cold start (Neon) | รอสักครู่ / ติดตั้งเป็น PWA |
| ข้อมูลไม่อัปเดต | Cache / ไม่ refresh | ดึงหน้าลงมา (pull-to-refresh) |
| แอปค้างบ่อย | RAM ไม่พอ / service worker ขัดข้อง | ปิดแอปอื่น / ล้าง cache |
| ไม่มีอินเทอร์เน็ต | Offline | เห็นหน้า /offline พร้อมปุ่มลองใหม่ |
