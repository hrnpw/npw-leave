🎯 การ Optimize Performance ที่แนะนำ

1. Database & API Layer

ปัญหาที่พบ:
- มี Prisma queries มากถึง 144+ ครั้ง
- ไม่มี connection pooling configuration
- Query logging เปิดใน development

แนะนำ:

1.1 เพิ่ม Connection Pooling
// lib/prisma.ts
export const prisma = new PrismaClient({
  log: process.env.NODE_ENV === 'development' ? ['error', 'warn'] : ['error'],
  datasources: {
    db: {
      url: process.env.DATABASE_URL,
    },
  },
});

// ปิด query logging เพื่อลด overhead

3. Image Optimization

ปัญหาที่พบ:
- public/icons/ ใหญ่ 1.3MB
- มีไฟล์ซ้ำซ้อน (icon-maskable, icon ธรรมดา)
- logo-npw-PDF.png ขนาด 235KB

แนะนำ:

3.1 Compress รูปภาพใหม่
# ใช้ sharp หรือ imagemin
npx @squoosh/cli --webp auto public/icons/*.png

3.2 ใช้ next/image แทน img tag
import Image from 'next/image';

<Image
  src="/icons/icon-192.png"
  width={192}
  alt="Icon"
  priority={false}
/>
